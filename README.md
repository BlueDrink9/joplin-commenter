# HTML Line Comment

Toggles HTML comments (`<!-- ... -->`) on the current line, across multi-line selections, or inline around partially selected text in Joplin on both desktop and mobile.

## Usage

- **Toolbar Button:** Click the **`</>`** (code) icon in the Markdown editor toolbar.
- **Keyboard Shortcut:** Press **`Ctrl+Alt+/`** (`Cmd+Alt+/` on macOS). You can customize this shortcut on desktop under **Tools → Options → Keyboard Shortcuts** (search for **Toggle HTML Comment**).
